# raveeto_media

Visuels publiés sur les réseaux de Raveeto (Instagram @raveeto_ca et Facebook).
Un dossier par lot : `AAAA-MM-JJ-lotN/` avec `carrousel/`, `stories/` et `reel/`.

Les fichiers servent de liens publics pour la programmation dans Metricool.
Prix relevés à la date du lot, avant taxes.
